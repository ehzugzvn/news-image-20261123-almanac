# ALMANAC — Monday 23 November 2026

A data almanac of one day's world news: the date as the masthead, four illustrated
lead stories, a numbered world map of 12 places with a UTC timeline rail, the day
in six numbers, ten verified tier-2 stories and two dozen briefs — every item from
Monday 23 November 2026, with a DATE CHECK strip naming the older stories left out.

Entry for the make.fun bounty [news-image-20261123](https://make.fun/bounty/news-image-20261123).

## How to run

- `python3 render.py` — regenerates `entry.png` (1024×1024) from the drawing code and fonts in `fonts/`.
- `python3 main.py` — copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
